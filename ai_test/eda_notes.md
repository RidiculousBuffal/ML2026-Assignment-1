# 年龄预测数据探索

来源：本项目 `train.csv`，600,000 行、17 列；未使用公开验证集，也未修改或训练模型。

## 怎样看这次探索

`age` 是目标，`id` 是编号，另外 15 列是预测特征。年龄均值 40.92 岁，中位数 39 岁，中间 50% 在 33–48 岁，95% 分位数为 58 岁，范围为 18–95 岁。

类别字段用年龄分位数箱线图，数值字段用固定区间分箱，避免长尾把图挤在一起。箱体为 25%–75% 分位数，须为 10%–90%，红菱形为均值；须外样本仍参与统计，只是不逐点绘制。每组标明样本数，不能只凭均值忽略分布重叠。

`group_association.csv` 的 eta² 是“按该字段分组，组均值能解释多少年龄方差”。数值字段的结果依赖分箱方式。这是训练集上的单字段描述，不能当成模型重要性、因果效应或验证集成绩，各字段的百分比也不能相加。

## 各字段的观察

| 字段 | 训练集中的现象 | 可形成的直觉 |
|---|---|---|
| `id` | 0–599999，唯一且递增；与年龄 Pearson r=0.0027 | 是编号，评测输入也不包含它，不作为特征 |
| `job` | 退休者均龄 60.49，学生 26.70；单字段 eta²=22.97% | 职业可先确定大致人生阶段，但同一职业内仍有明显年龄差异 |
| `marital` | 单身 33.30，已婚 43.33，离异 45.37；eta²=20.34% | 除职业外很值得关注。多数职业内，单身人群仍更年轻 |
| `education` | primary 46.25，secondary 40.17，tertiary 39.59，unknown 44.46 | 更可能包含代际与职业构成信息，不能理解成学历导致年龄变化 |
| `default` | yes 39.84，no 40.94；yes 只占 1.70% | 单独区分年龄的能力弱，暂不作为重点，但未验证应删除 |
| `balance` | 负余额 39.43，零余额 42.55，1–500 为 39.19，2001–5000 为 42.67 | 不能简单认为越有钱越年长；负数、零、正数值得分开观察 |
| `housing` | 有房贷 39.26，无房贷 42.93；eta²=3.27% | 有房贷可能标记某个人生阶段；无房贷同时包含年轻人、已还清者等，不能解释成是否有房 |
| `loan` | yes 40.52，no 40.99 | 单字段差异很小；与房贷不是同一个特征 |
| `contact` | telephone 47.69，cellular 40.50，unknown 40.90；telephone 有 25,303 人 | 联系渠道含有人群构成信息；电话组并非只有极少数样本 |
| `day` | 六个日期区间均龄在 39.71–41.65；线性 r=-0.0162 | 单独信号偏弱，是营销日期而非出生日期 |
| `month` | 5月均龄 38.98，10月 45.77；5月 182,621 人，12月仅 1,630 人 | 月份可能反映不同批次联系了哪些人；不能将月份数字强行理解成线性年龄关系 |
| `duration` | 分箱均龄 39.24–41.79；线性 r=-0.0033 | 相关系数接近零不代表完全无关系，但目前分箱差异也明显弱于职业和婚姻 |
| `campaign` | 不同次数组均龄 40.32–41.36；99% 分位数14次，最大58次 | 单独信号较弱，有长尾；不值得因极端大值就直接删样本 |
| `pdays` | -1 占89.68%；已联系组各区间均龄约39.75–41.53 | -1 是“未联系过”，不是普通的负天数，应单独标记 |
| `previous` | 0 占89.68%；99% 分位数6，最大200 | 零膨胀和长尾明显；可分开表达是否联系过与联系次数 |
| `poutcome` | success 均龄43.13、中位数39、标准差14.12；unknown 占89.68% | 成功组包含更宽的年龄分布，不能把均值较高理解成组内人人都偏老 |

## 比单字段更有用的关系

1. **职业与婚姻值得联合考虑。** management 的已婚均龄42.53、单身33.86；technician 分别41.79、33.47。婚姻带来的组间差异并没有在固定职业后消失。不过，这仍只固定了职业，不能视为已排除所有混杂因素。
2. **房贷的差异随职业改变。** blue-collar 有房贷39.21、无房贷43.95；management 39.45与40.82；student 则27.24与26.51，方向相反。这提示统一加减一个“房贷年龄偏移”可能过于简单。
3. **月份反映人群组成的可能性很高。** 10月退休者占19.3%，5月仅2.2%；同时9月学生占8.8%，5月仅1.3%。月份的年龄分布差异至少伴随着职业组成差异，不能直接推断为季节造成。
4. **三项历史联系字段高度重复。** `pdays=-1`、`previous=0`、`poutcome=unknown` 比例都约89.7%。前两项的“是否无历史”判定只有21行不一致，应保留并检查，不要擅自强行纠正。`unknown` 既可能表示未记录，也可能对应没有历史结果，不能全部当随机缺失删除。

## 对下一步建模的经验判断

- 优先把 `job`、`marital`、`education`、`housing` 表达好，再观察 `contact`、`month`、`balance` 的增量作用。描述性排序只能指导实验顺序。
- 类别特征若进入线性模型，优先考虑 one-hot；不要随意编码成0、1、2后就把类别距离当成真实数值。可以实验 `job × marital`、`job × housing` 的交叉特征，但稀有组合需要正则化或回退。
- `balance` 保留负数与零的含义，可尝试符号标记、零标记和带符号的对数变换；`duration`、`campaign`、`previous` 可尝试 log1p。变换是否有益尚未验证。
- `pdays` 可以用“是否联系过”加“联系过时的间隔”表达，避免把 -1 和真实天数混在同一条直线上。其他历史字段是否保留，应通过消融实验决定。
- `loan`、`default` 等单字段均值差异小，不等于与其他字段组合后一定没有价值。60万样本下，不应仅以统计显著性替代预测收益。
- 年龄主体集中在33–48岁，退休者、学生及高龄尾部相对少。后续除整体RMSE/MAE外，应按职业和年龄段查看误差，防止整体还行但总把两端预测回中间。
- 先在训练集内部固定验证划分。任何基于年龄的分组均值编码都只能从训练折计算，再应用到验证折；不要在全训练集上算完编码后才划分。当前探索未进行预测实验，不能据此声称某个方案已经提升效果。

## 数据质量与复现

没有空单元格，`id` 无重复；去除 `id` 后也没有整行重复。字符串 `unknown` 则大量存在：contact 30.90%，education 2.84%，job 0.39%，poutcome 89.68%。余额有13.96%为负、12.43%为零；这是需要保留的观测状态，不应自动判为错误。
