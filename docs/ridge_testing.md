# 岭回归实现与测试

## 已实现的流程

- `model.py`：`Preprocessor` 负责清洗及编码，`Model` 使用 NumPy 求解岭回归。
- `solution.py`：初始化时从相邻的 `train.csv` 读取全部训练记录并训练；`forward` 复用训练参数。
- `test_ridge.py`：固定种子 42，从真实训练 CSV 随机划分 80% 训练、20% 验证。所有预处理仅在这 80% 上拟合，不读取公开集。

不使用 `id`，不对标签做异常裁剪或去重；非有限/无法解析的标签直接报错，避免悄悄改变监督目标。

类别统一去首尾空格、转小写，使用训练词表独热编码，保留业务 `unknown`，为缺失及未见类别预留独立位置。数值非法字符串、无穷值、非法日期和负的时长/次数视为缺失，使用训练中位数填补并增加缺失标记。余额允许为负。`pdays=-1` 用 `never_contacted` 标记，天数分量填补。数值用训练均值及标准差标准化，常数列尺度设为 1。

实现采用以下目标，截距不正则化：

$$
\min_{w,b}\sum_{i=1}^n(y_i-x_i^Tw-b)^2+\alpha\|w\|_2^2
$$

默认 `alpha=1.0`。注意这是损失**求和**的约定，与方案文档中的平均损失约定不同：平均损失的正则系数为 $\lambda$ 时，对应这里的 $\alpha=n\lambda$。

## 运行方法

在项目根目录、已安装 `requirements.txt` 的 Python 环境下执行。下面限制 BLAS 线程以避免小矩阵运算过度开线程；这是可选性能设置，不影响算法含义。

```bash
# 快速验证：随机抽取 20000 条，再做 80%/20% 划分
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python test_ridge.py --rows 20000

# 全部 train.csv 的内部留出验证
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python test_ridge.py

# 比较其他正则强度；优先依据内部验证选择，不追逐公开成绩
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python test_ridge.py --alpha 10

# 完整公开评测：重新使用全部 train.csv 训练，生成 result.json
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python evaluate.py
```

内部测试还自动检查：单条与批量预测一致、同实例 10 线程推理一致、推理未修改权重，以及未见类别、空类别、无穷余额、缺失数值、非法日期和 `pdays=-1` 的处理。

## 本次实际结果

环境：NumPy 1.24.3、pandas 2.0.3，默认 `alpha=1.0`。

| 数据划分 | MAE | MSE | RMSE |
|---|---:|---:|---:|
| 内部验证均值基线 | 8.398144 | 101.450602 | 10.072269 |
| 内部验证岭回归 | 6.305371 | 60.047501 | 7.749032 |
| 完整公开验证集 | 6.299269 | 59.946135 | 7.742489 |

内部划分训练 480000 条、验证 120000 条，编码后 75 维，总测试耗时约 12.16 秒。公开评测打印的 `Time` 为 7.401 秒，详细耗时以 `result.json` 的各字段定义为准。耗时依赖机器，不代表其他环境的保证。

公开 RMSE 略高于 README 的 7.7398 参考值，尚未超过参考基线；本次没有进行超参数搜索。另已用小型数值样本对照增广正规方程，检查了闭式解、截距不正则化和常数列处理。
